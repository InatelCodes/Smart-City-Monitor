# Smart City Monitor

Projeto prático da disciplina de Sistemas Operacionais.

## Sobre

O Smart City Monitor é uma aplicação que simula uma central de monitoramento de uma cidade inteligente.

A aplicação irá receber e processar informações provenientes de diferentes sensores da cidade.

Os principais sensores serão:

- Trânsito
- Clima
- Consumo de energia
- Qualidade do ar

## Threads

Cada tipo de sensor será executado de forma concorrente utilizando Threads, permitindo que diferentes informações sejam coletadas e processadas simultaneamente.

## Tecnologias

- Java
- Maven
- Threads
